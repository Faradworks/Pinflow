# Contributing to Pinflow

Thanks for your interest in contributing! Pinflow is open source under the
[GNU General Public License v3.0 or later](./LICENSE).

## Getting started

- Build, run, and architecture notes live in the [README](./README.md).
- For bugs and feature ideas, please open an issue before a large PR so we can
  discuss the approach first.

## Pull request basics

1. Fork the repo and create a topic branch.
2. Keep changes focused, and match the style of the surrounding code.
3. Make sure the app builds (`npm run build` in `apps/desktop`) and the Python
   service imports cleanly.
4. Open the PR and address review feedback.

By submitting a contribution, you certify that you wrote it (or otherwise have
the right to submit it) and agree to license it under the terms above.
