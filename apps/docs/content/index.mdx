# Pinflow

**An open-source agentic assistant for electronics design.** Pinflow is a
chat-driven co-designer that works alongside [KiCad](https://www.kicad.org/) —
the conversation on one side, a live schematic view on the other — automating
the tedious parts of schematic capture, part selection, and layout so you can
focus on design intent.
